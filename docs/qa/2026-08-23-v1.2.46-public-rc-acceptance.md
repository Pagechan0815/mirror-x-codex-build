# Mirror X Codex v1.2.46 PUBLIC-RC 对外分发验收报告

## Product Goal Understanding

- `Target users`：获取转发包的其他 Windows 用户，包括已安装、未安装或安装了过旧 Codex 的用户。
- `Core scenario`：解压并核对 -> 安装 -> 检测/安装/更新 Codex -> 确认 Full access -> 验证至少一个文本 Key -> 选择模型与 Pure/Mixed -> 建立基线并事务应用 -> 启动 -> 需要时恢复。
- `Primary user success outcome`：收件人不依赖制作机状态，不手改 `.codex`，可选模型并创建对话，可修改工作区，并能回到接入前状态。
- `Business goal`：交付可转发、按当前 Windows 用户安装、不携带制作机凭据与会话的 Windows x64 RC。
- `Non-goals`：不承诺 ARM64、32 位、大幅精简系统、所有企业策略、无效/无权 Key 或所有第三方插件免登录；不在包内分发 Key。
- `Quality risks`：Provider 表缺失、模型目录为空、Pure/Mixed 登录态串线、Full access 未真正生效、恢复到错误 CODEX_HOME、低磁盘半写入、Codex/WebView2/winget 缺失、旧 ZIP 误发、未签名文件被拦截。
- `Assumption`：收件人使用支持范围内的 Windows x64，有至少一个有效文本 Key，网络能访问对应 API，且设备策略允许 Codex Full access。

### 4. Optimization Proposals

#### Immediate fix (before unrestricted public release)

1. 在一次性 Windows 11 x64 VM 和一台更新完整的 Windows 10 x64 上，用专用测试 Key 分别跑 Pure、Mixed、Full access、安装、升级、恢复、卸载。
2. 为 3 枚 EXE 和 setup 加 Authenticode 签名。

#### Short-term improvement (next iteration)

1. 在 CI 加 Windows clean-runner 安装器静默安装、文件版本、启动烟测、Provider 契约与卸载恢复。
2. 增加一键导出脱敏诊断包，固化 Windows/Codex/安装来源/Full access/Provider 证据且不导出 Key。

#### Structural optimization (root cause)

1. 发布流水线绑定 source fingerprint、Release EXE、installer payload、说明和最终 ZIP；任一源码变化自动作废旧产物。
2. 固定兼容矩阵：Windows 11、Windows 10、无 WebView2、无 winget、低磁盘、组织策略、Store/Standalone Codex、自定义 CODEX_HOME。
